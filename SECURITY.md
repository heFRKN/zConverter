# Security

Please do not open a public issue for security problems. Report them privately via [GitHub security advisories](https://github.com/heFRKN/zConverter/security/advisories/new).

Official builds are published only on this repository's [Releases](https://github.com/heFRKN/zConverter/releases) page. Copies downloaded elsewhere may have been modified.

---

**Türkçe:** Güvenlik açıklarını herkese açık issue yerine [özel güvenlik bildirimi](https://github.com/heFRKN/zConverter/security/advisories/new) ile bildir. Resmi sürümler yalnızca bu deponun Releases sayfasından dağıtılır.
