# Güvenlik / Security

Bir güvenlik açığı bulursan lütfen herkese açık bir issue açma; GitHub'ın [özel güvenlik bildirimi](https://github.com/heFRKN/zConverter/security/advisories/new) özelliğini kullan.

Please do not open a public issue for security problems. Report them privately via [GitHub security advisories](https://github.com/heFRKN/zConverter/security/advisories/new).

Resmi sürümler yalnızca bu deponun [Releases](https://github.com/heFRKN/zConverter/releases) sayfasından dağıtılır. Başka bir yerden indirilen kopyalar değiştirilmiş olabilir.

Official builds are published only on this repository's Releases page.
